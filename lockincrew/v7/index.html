/manifesto — six rules. no slack channels needed.

presence is not output. we measure ourselves in shipped artifacts, not hours of green dot.

fewer rituals.

no daily standup. no retro about the retro. one written brief, one done thing, one demo.

the keyboard is the artifact.

strategy decks rot. running code compounds. we bias hard toward the latter.

small units, sharp scope.
